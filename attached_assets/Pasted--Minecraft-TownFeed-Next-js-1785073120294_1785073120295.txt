Задача: Создать сайт-каталог городов Minecraft-сервера «TownFeed» с нуля. Использовать стек: Next.js 14 (App Router), Tailwind CSS, TypeScript. В качестве базы данных использовать Supabase.

Дизайн:

    Тёмная тема.

    Шрифты: Inter для основного текста, пиксельный шрифт (например, 'Press Start 2P') для заголовков и названий городов.

    Карточки с закруглёнными углами и тенями.

    Фавикон в виде пиксельного здания.

Основной функционал:

    Главная страница (/):

        Список всех добавленных городов в виде сетки карточек.

        Каждая карточка показывает: название (пиксельным шрифтом), описание (кратко), репутацию, размер казны, дату последнего обновления.

        Поисковая строка сверху с нечётким поиском. Поиск должен находить города даже при опечатках, неправильной раскладке или неполном вводе названия (например, «скобка гоад» находит «СкобкаГрад»). Для этого использовать библиотеку Fuse.js (или аналогичную) на клиенте.

        Справа или сверху небольшой блок «Последние новости», которые добавляются из админ-панели.

    Страница города (/city/[id]):

        Коллаж из 3-4 фотографий (обычный grid).

        Подробные характеристики: полное описание, казна, репутация, основатель, население, дата основания/последнего обновления, координаты (X, Z).

        Блок «Как попасть»: серый фон, код /t spawn [НазваниеГорода] с кнопкой копирования в буфер обмена.

        Ссылка «Показать на карте» (внешняя ссылка с иконкой).

        Секция комментариев снизу:

            Форма отправки: поле ввода ника и поле текста.

            Кнопка «Войти через Google» (Google OAuth) — необязательная опция, чтобы оставить коммент как авторизованный юзер.

            Гости могут просто вписать ник и отправить сообщение.

    Админ-панель (/admin):

        Простой логин по паролю (пароль задаётся в переменных окружения).

        Форма добавления нового города: Название, Полное описание, Казна, Репутация, Основатель, Население, Координаты (X, Z), Команда для телепорта, Ссылка на онлайн-карту, Ссылки на 3-4 фото (через запятую).

        Форма добавления новости: Текст новости.

        Список добавленных городов с возможностью удалить любой город.

База данных (Supabase):
Создай SQL запросы для следующих таблиц:

    cities: id, name, description (text), treasury (text), reputation (text), founder (text), population (text), coordinates_x (text), coordinates_z (text), last_updated (date), map_link (text), spawn_command (text), photos (text array).

    comments: id, city_id (foreign key), nickname (text), avatar_url (text), content (text), created_at (date).

    news: id, content (text), created_at (date).
